1) Description on code fix:  
The defect GAQ20T-479 requires removing unnecessary fields from the "Set Jira Credentials" form used for Jira Zephyr Squad integration. The root cause analysis indicates two main issues: configuration-wise, the form includes obsolete fields beyond the mandatory ones (Jira Username, Jira API Token, Zephyr Access Key, Zephyr Secret Key), and from a UI/UX perspective, the interface is cluttered with these obsolete fields causing confusion and misconfiguration. Additionally, the validation logic currently does not enforce strict checks to ensure only these mandatory fields are submitted, which can lead to errors downstream.

The fix addresses these issues by:  
- Updating the UI component responsible for rendering the Jira credentials form to only include the mandatory fields. This improves clarity and reduces user confusion.  
- Modifying the validation service to strictly validate only the mandatory fields, rejecting or ignoring any extraneous inputs.  
- Enhancing user feedback by ensuring validation errors clearly indicate missing mandatory fields or presence of invalid fields.  

This approach directly resolves the root causes by aligning the configuration and UI with the defined mandatory credentials and enforcing strict validation, thereby preventing misconfiguration and improving user experience.

function validateCredentials(credentials) {
  const errors = [];

  // Validate mandatory fields presence
  if (!credentials.jiraUsername) {
    errors.push("Jira Username is required.");
  }
  if (!credentials.jiraApiToken) {
    errors.push("Jira API Token is required.");
  }
  if (!credentials.zephyrAccessKey) {
    errors.push("Zephyr Access Key is required.");
  }
  if (!credentials.zephyrSecretKey) {
    errors.push("Zephyr Secret Key is required.");
  }

  // Reject any extra/unnecessary fields to prevent misconfiguration
  const allowedFields = ["jiraUsername", "jiraApiToken", "zephyrAccessKey", "zephyrSecretKey"];
  Object.keys(credentials).forEach(field => {
    if (!allowedFields.includes(field)) {
      errors.push(`Field '${field}' is not allowed.`);
    }
  });

  return errors;
}


Changes Made:  
- Added logic to detect and reject any fields outside the mandatory set.  
- This prevents obsolete fields from being submitted or processed, aligning with configuration requirements.  
- Maintained existing mandatory field checks to ensure completeness.
